# Chrome Web Store 發布清單

## 送審前

1. 填入 `STORE_LISTING.md` 的開發者名稱、支援信箱與隱私權政策 HTTPS 網址。
2. 在 `PRIVACY_POLICY.md` 填入相同的公開聯絡方式，並將政策發布到該網址。
3. 停用 Tampermonkey 版本，以「載入未封裝項目」完成訂單頁與菜單頁手動測試。
4. 確認 `manifest.json` 的版本高於先前已上傳版本。
5. 確認商店截圖與目前版本的實際介面一致。
6. 執行專案的靜態與封裝檢查。

## Dashboard

1. 上傳發布 ZIP；`manifest.json` 必須位於 ZIP 根目錄。
2. 貼上 `STORE_LISTING.md` 的簡短說明、詳細說明與單一用途。
3. 上傳 128×128 圖示、440×280 宣傳圖及至少一張 1280×800 截圖。
4. 在 Privacy practices 填寫權限理由、資料處理與「無遠端程式碼」聲明。
5. 設定公開或非公開發佈範圍，再送審。

發布帳號、兩步驟驗證、註冊費、隱私權政策託管及最終送審由發布者帳號持有人處理。
