# 安全設計

## 信任邊界

- Content script 執行於 Chrome 的隔離世界，不存取 Nidin 的 JavaScript 變數。
- 暫存只經由 service worker 寫入 `chrome.storage.session`；網站程式不能直接讀寫。
- Service worker 只接受來自 `https://order.nidin.shop` 且具有有效分頁 ID 的訊息。
- Extension 沒有遠端程式碼、第三方套件、分析或額外網路請求。

## 購物車防呆

- 匯入 JSON 會檢查格式、筆數、大小、店家 ID、價格、數量與必要欄位。
- 驗證階段不加入購物車。
- 必須由使用者按「開始加入」並再次確認，才會逐筆操作 DOM。
- 加入前再次檢查規格、數量、訂購人與總價。
- 每列只點擊一次加入按鈕。
- 點擊後必須觀察到購物車狀態或成功通知；結果不明時停止，不自動重試。
- 不會前往結帳或送出訂單，也不會清空既有購物車。

## 維護原則

網站改版後先更新 `SELECTORS`，不要放寬完整名稱、店家或價格比對。若無法唯一辨識商品、規格或購物車，應維持停止並交由人工確認。
