# 隱私權政策

生效日期：2026-07-25

「Nidin 訂單工具（非官方）」只為了協助使用者在 Nidin 訂單頁匯出訂單資料，以及在菜單頁驗證並重新加入品項。

## 處理的資料

Extension 只在使用者開啟 `order.nidin.shop` 時處理下列資料：

- 訂單品項、規格、數量、價格、收款狀態、店家 ID 與訂單 ID。
- 訂購人顯示名稱。
- 使用者主動匯入的訂單 JSON。
- 未完成流程的品項狀態與購物車識別資訊。

Extension 不讀取密碼、Cookie、登入權杖或信用卡等付款憑證。

## 使用、儲存與刪除

- 資料只用於畫面上的匯出、驗證與重新加入功能。
- 未完成流程只暫存在本機 extension 的 `chrome.storage.session`，並依 Chrome 分頁隔離。
- 關閉該分頁、關閉 Chrome、停用、更新或重新載入 extension 時，暫存資料會清除。
- 使用者也可以在懸浮介面按「清除」立即刪除暫存。
- 匯出的 JSON、CSV 與剪貼簿內容由使用者自行保存與管理。

## 傳輸與分享

Extension 不會把上述資料傳送至開發者、分析服務、廣告服務或任何其他第三方，也不會出售或分享資料。Extension 沒有額外的網路請求或遠端程式碼。

使用者與 Nidin 網站本身的互動仍受 Nidin 的條款與隱私政策約束；本 extension 與 Nidin 並無官方關係。

## 權限

- `storage`：保存目前分頁尚未完成的重新訂購流程。
- `https://order.nidin.shop/*`：讀取訂單與菜單畫面，顯示操作介面，並在使用者確認後操作商品 DOM。
